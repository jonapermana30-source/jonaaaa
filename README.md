# JONA GEAR — Razer BlackWidow V4

Website toko online satu produk untuk kebutuhan presentasi.

## File
- `index.html` — seluruh website (HTML, CSS, dan JavaScript dalam satu file).
- `README.md` — panduan ini.

## Cara memasang di GitHub
1. Buka repository GitHub yang akan digunakan.
2. Pilih **Add file → Upload files**.
3. Upload `index.html` dan `README.md` dari folder hasil ekstrak ZIP.
4. Klik **Commit changes**.
5. Buka **Settings → Pages**.
6. Pada **Build and deployment**, pilih **Deploy from a branch**.
7. Pilih branch `main` dan folder `/ (root)`, lalu **Save**.
8. Tunggu proses publikasi, lalu buka alamat GitHub Pages yang ditampilkan.

## Cara mengedit
Buka `index.html` di repository GitHub, tekan ikon pensil, ubah teks/harga sesuai kebutuhan, lalu klik **Commit changes**.

## Catatan
- Harga dan ulasan di halaman adalah contoh untuk presentasi, bukan penawaran resmi.
- Tombol beli dan keranjang masih berupa simulasi; belum terhubung ke pembayaran atau sistem pesanan.
- Ilustrasi keyboard dibuat dengan CSS, sehingga tidak memerlukan file gambar tambahan.
